# Site saharahub — mise en ligne

Fichiers : `index.html` (le site complet, une seule page, FR / AR / EN) et `DESIGN.md` (couleurs, polices, composants).

## 1. Activer le formulaire (5 minutes, gratuit)
Les messages arrivent dans la boîte de l'entreprise **sans que l'adresse apparaisse sur le site**.
1. Aller sur https://web3forms.com → « Create your Access Key » → saisir l'adresse e-mail de l'entreprise.
2. Copier la clé reçue par e-mail.
3. Dans `index.html`, chercher `YOUR_WEB3FORMS_ACCESS_KEY` et le remplacer par la clé.
Tant que la clé n'est pas mise, le formulaire affiche « en cours de configuration » et n'envoie rien.

## 2. Mettre en ligne
N'importe quel hébergeur de fichiers statiques convient : déposer `index.html` à la racine du site
(par ex. Netlify Drop, Vercel, GitHub Pages, ou l'hébergement de votre nom de domaine .ma).

## 3. À compléter quand vous le souhaitez
- Captures d'écran réelles de EduPlay 3D, Skilled Volunteer MA et ARDOUKH 3D (les visuels actuels sont des illustrations).
- Une courte description de chaque projet et, si possible, un résultat.
- Image de partage (og:image) et nom de domaine définitif.
- Police arabe Janna LT : si vous achetez la licence, remplacer « Readex Pro » / « IBM Plex Sans Arabic » dans le CSS.

# موقع saharahub — النشر

1. **تفعيل الاستمارة:** ادخل إلى web3forms.com، وأدخل بريد الشركة لتحصل على مفتاح (Access Key)، ثم ضعه مكان `YOUR_WEB3FORMS_ACCESS_KEY` في ملف index.html. تصل الرسائل إلى بريدك دون أن يظهر عنوانه في الموقع.
2. **النشر:** ارفع ملف index.html إلى أي استضافة (Netlify أو Vercel أو استضافة نطاقك).
3. **للإكمال لاحقاً:** لقطات شاشة حقيقية لمشاريعكم الثلاثة، ووصف قصير لكل مشروع، وصورة المشاركة، والنطاق النهائي.
